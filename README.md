# muvio

Self-hosted, dark, minimal downloader and local transcription interface. Supports public media sources handled by yt-dlp. Private anonymous browser sessions, optional temporary storage, and rolling download quotas. No accounts, ads, or analytics.

## Run

Docker: `docker compose up --build` and visit http://localhost:3838. The port binds to **localhost only**. Docker installs FFmpeg and Python dependencies. Transcription uses CPU by default; a GPU needs a custom CTranslate2/CUDA image. The existing `./data:/app/data` bind mount is retained: its directory must be writable by container UID 10001 (prepare permissions deliberately; do not change unrelated host directories).

Local (Python 3.11+, FFmpeg installed): `python3 -m venv .venv`, `. .venv/bin/activate`, `pip install -r requirements.txt`, `uvicorn main:app --host 127.0.0.1 --port 3838`. To enable vocal separation, run `pip install demucs` and enable it in Settings. From the project root, start with the single uvicorn command after dependencies are installed.

To use administration, copy `.env.example` to `.env`, set a long random `API_KEY`, and enter it under **Settings → Use key**. Settings, models, diagnostics and transcription require this key even when anonymous downloads are enabled. To use Whisper, click **Download Whisper model** in Settings; until then transcription returns `whisper.model_missing`. To use optional Demucs, install the package, then explicitly download its weights in Settings. Inference never starts a model download. Optional AI cleanup is opt-in and sends transcript text to the configured endpoint; local Ollama is supported.

**Non-sensitive deployment variables are grouped and commented in `compose.yml`.** `.env` holds only `API_KEY`, optional `SIGNING_SECRET` and `LLM_API_KEY`. Compose's `environment` takes precedence over `.env`; edit policy in Compose, not in `.env`. Local runs may use these same environment variables directly or in `.env`. Editable admin preferences in `data/config.json` still override their environment defaults; retention, quotas and security policy are not editable there.

- `PERSIST_STORAGE: "true"` (default): new results stay in `OUTPUT_DIR` without automatic expiry.
- `PERSIST_STORAGE: "false"`: new media, uploads, intermediates and history use ordinary container disk in `/tmp/muvio`, **not the data volume, RAM, or tmpfs**. Results expire one hour **after completion**; cleanup runs at startup and every 60 seconds. The UI attempts a direct browser save only for temporary video/audio/subtitle jobs started by that page, once, even with Activity closed. Keep the page open; browsers may block this. The manual save button always remains. Transcription exports stay manual.
- `ANON_DOWNLOAD_LIMIT: "5"`: five accepted download/subtitle jobs per anonymous session in a rolling 24-hour window. **`"0"` means unlimited**, while capacity/IP controls remain enabled. Validation/collection selectors and pre-start cancellations do not consume quota. Started failures/cancellations do. Quotas survive restarts; repeated saves do not count again.
- `STATE_DIR` and `MODELS_DIR` remain persistent in both modes. Keep the state directory and signing secret: without `SIGNING_SECRET`, a private `STATE_DIR/signing.key` is generated. Deleting cookies, using another browser, or losing the key loses access to that anonymous history. Cookies are not an abuse-proof per-person identity.

Existing downloads are neither moved nor deleted by changing retention mode. Ownerless legacy history is backed up during schema migration and is visible only to administrators, never assigned to the first visitor. Set `STATE_DIR` explicitly before changing `OUTPUT_DIR`; for old local installations that omit it, the previous `OUTPUT_DIR.parent` state location remains compatible. Temporary files survive a process/container restart if its writable layer survives, but disappear on container recreation. New temporary history is never copied to the persistent state DB. See [storage, quotas and rollout notes](docs/persistence-multiuser.html).

The API lives at `/api` and OpenAPI docs at `/docs`. Start with GET `/api/session` and retain its HttpOnly cookie. All writes require `X-Muvio-Request: 1` and same-origin browser requests. POST `/api/download` returns `local-processing` with `output.job_id`, or `picker` for a collection. Send `Idempotency-Key` for retries (including multipart uploads; actual content is hashed). Poll `/api/jobs/{id}` for fresh signed download links. GET `/api/jobs?limit=30&cursor=...` returns `{items, next_cursor}`; details, listing, cancellation and SSE are owner-scoped. Administrative access uses `Authorization: Api-Key ...` but does not merge browser identities or expose other visitors' work. GET `/api/events` streams only that session's progress. Signed file URLs are bearer capabilities valid for 15 minutes: someone you give one to can use it, but expiry of the result still applies. Do not log their query strings at the proxy.

Admin-only POST `/api/transcribe` accepts JSON `{ "url": "...", "mode": "quick" }` or multipart `file` with JSON `options`. Transcripts are exported as TXT, SRT, VTT, and word-timed JSON. All errors use `{ "status": "error", "error": { "code": "...", "context": { "message": "..." } } }`. Quota exhaustion is `429 / quota.exceeded` with `Retry-After`, `limit`, `remaining` and `next_available_at` (Unix seconds); unlimited `remaining` is `null`. Processing state `done` is separate from availability `available`, `expired` or `missing`.

The UI uses plain ES modules and serves `app/web/css/custom.css` directly. Jost is bundled locally under `app/web/fonts/` with its SIL Open Font License. No Node, CSS build, font service, or runtime CDN is needed. Edit `custom.css` to change the design.

Downloads start with automatic settings: video targets the highest available resolution at or below 720p (or the lowest available if all exceed it), preferring MP4/H.264 with AAC at that resolution. If needed, another available combination is shown by its actual format. Audio defaults to MP3 at 320 kbps. Advanced controls expose only compatible source combinations; an explicitly selected resolution must exist for that combination. Video is not re-encoded. A larger audio bitrate or lossless output cannot recover quality already lost at the source.

Video and audio downloads prefer the source's identified **original audio language**, before bitrate or container preferences. Each card shows the selected language and offers the available language tracks (including regional variants). If the source does not identify the original or the language, the card says so instead of guessing. Unmarked tracks use a stable language-code order, not the server region's default. Only existing source audio is offered; this does not translate or generate a dub. An explicitly selected language never falls back to another language, including when a queued download refreshes its metadata. `/api/info` exposes `audioTracks`, `defaultAudioLanguage`, and language-specific `videoOptions`; `/api/download` accepts `audioLanguage` (default `"original"`, or an available language tag such as `"en"` or `"es-419"`). Audio language is separate from subtitles and Whisper's recognition language.

Offline checks: `python -m pytest`. Pure frontend selection tests: `node --test tests/test_ui.mjs`. Optional real-browser checks use Playwright: `pip install playwright`, `python -m playwright install chromium`, then `python -m pytest tests/test_browser.py`. Browser tests use mocked media and do not download from media websites.

**Deployment boundary:** One application process/instance per state directory; an exclusive lock rejects multiple workers. Do not add Uvicorn workers/replicas. Accounts, registered-user quotas, production capacity measurements and public rollout are deferred. Initial URL validation alone does **not** prevent SSRF through redirects/DNS rebinding: enforce outbound network restrictions before accepting untrusted public traffic. HTTPS, `COOKIE_SECURE=true`, an exact `PUBLIC_ORIGIN`, explicit trusted-proxy settings, proxy transfer/body limits and capacity/egress budgets must be reviewed before exposing this installation. The Docker command trusts no forwarded headers by default. The included capacity values are conservative configurable controls, not measured production capacity.

**Responsible use:** Save only media you have permission to download. Respect copyright and platform terms; do not redistribute others' work. No DRM circumvention or private-content access is implemented. Server expiry does not delete a user's downloaded copy or securely erase the underlying disk.
